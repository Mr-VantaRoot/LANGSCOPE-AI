# Archived LANGSCOPE AI artifacts

These folders are retained for provenance and are not the current model or final evaluation.

- `tatoeba_nine_pre_final/` contains the earlier nine-label Tatoeba model that was replaced by the final model. It has no final held-out test evaluation.
- `tatoeba_nine_csv_parser_run/` contains an intermediate run made during finalization. The loader used a CSV parser on raw TSV data and counted rows incorrectly. Its test predictions are preserved only so every sentence ID it scored can be excluded from the final evaluation. **Do not cite its model, metrics, confusion matrix, or failure cases.**
- `../tatoeba/` contains the older ten-label Tatoeba experiment. Its test set was already scored and Oromo training/validation used FLORES+ dev.
- Root `artifacts/` model and metrics files were generated by the older FLORES+ experiment. They are preserved for historical comparison only; FLORES+ is not the current model's training data.

The current app loads only `artifacts/tatoeba_nine/`. Its metrics are in that folder's `metrics.json`.
